# Web 版本布局指南

## 🎨 三栏布局结构

Web 版本采用现代化的**左中右三栏布局**，基于 TailwindCSS 12列网格系统。

```
┌──────────────────────────────────────────────────────────────┐
│                          Header                               │
├──────────┬──────────────────────────────────┬────────────────┤
│  左栏    │           中栏（预览）            │     右栏       │
│  (3列)   │            (6列)                │    (3列)       │
│          │                                 │                │
│ 渐变类型  │                                 │  纹理效果      │
│ 色标编辑  │        预览画布                  │  ✨ Perlin    │
│ 角度控制  │      (实时/生成)                 │  🌫️ 磨砂     │
│          │                                 │  🎞️ 胶片     │
│          │      [生成渐变按钮]               │  🎭 晕影      │
│          │                                 │                │
│          │                                 │  预设库        │
│          │                                 │  (单列滚动)     │
└──────────┴──────────────────────────────────┴────────────────┘
```

## 📐 列宽分配

使用 Tailwind 的 `grid-cols-12` 系统：

| 区域 | TailwindCSS 类 | 宽度占比 | 用途 |
|------|---------------|---------|------|
| **左栏** | `lg:col-span-3` | 25% | 渐变设计控制 |
| **中栏** | `lg:col-span-6` | 50% | 预览和生成 |
| **右栏** | `lg:col-span-3` | 25% | 效果和预设 |

## 📦 左栏内容（渐变设计）

### 1. 渐变类型卡片
- **线性渐变**：0-360° 角度控制
- **径向渐变**：从中心向外扩散

### 2. 色标编辑器
- 颜色选择器（color input）
- 位置滑块（0-100%）
- 添加/删除色标按钮
- 最多支持 20 个色标

### 3. 角度控制（线性渐变专用）
- 滑块：0-360°
- 实时显示角度数值
- 动态显隐（仅线性渐变时显示）

## 🖼️ 中栏内容（预览区域）

### 预览画布
- **尺寸**：800 × 600 像素
- **比例**：4:3 宽高比
- **状态**：
  - 实时 CSS 预览（未生成时）
  - Python 生成图像（点击生成后）
  - 加载中动画（生成过程中）

### 操作按钮
- **生成渐变**：调用 Python 后端生成高质量图像
- 大号按钮，渐变背景，阴影效果

## ⚡ 右栏内容（效果和预设）

### 1. 纹理效果
四种专业效果按钮：
- ✨ **Perlin 噪点**：自然纹理质感
- 🌫️ **磨砂玻璃**：毛玻璃模糊效果
- 🎞️ **胶片颗粒**：复古胶片质感
- 🎭 **晕影效果**：边缘暗角效果

### 2. 预设库
- **布局**：单列垂直滚动
- **高度**：每个预设 80px
- **交互**：
  - 悬停显示预设名称
  - 点击加载预设配置
  - 自动生成渐变图像
- **最大高度**：384px（约 5 个预设可见）

## 🎭 响应式设计

### 桌面端（lg 及以上，≥1024px）
```css
grid-cols-12  /* 12列网格 */
gap-6         /* 列间距 24px */
```

### 移动端（< 1024px）
```css
grid-cols-1   /* 单列堆叠 */
```

布局顺序（从上到下）：
1. 左栏控制
2. 中栏预览
3. 右栏效果

## 🎨 视觉设计特点

### 玻璃态设计（Glassmorphism）
```css
backdrop-blur-xl      /* 背景模糊 */
bg-white/70          /* 70% 白色透明度 */
border-white/20      /* 20% 白色边框 */
```

### 阴影系统
- **卡片阴影**：`shadow-xl shadow-gray-200/50`
- **按钮阴影**：`shadow-lg shadow-indigo-500/30`
- **悬停增强**：`hover:shadow-xl hover:shadow-indigo-500/40`

### 圆角设计
- **卡片**：`rounded-2xl` (16px)
- **按钮/输入**：`rounded-xl` (12px)
- **小元素**：`rounded-lg` (8px)

### 渐变背景
```css
/* 页面背景 */
bg-gradient-to-br from-indigo-50 via-white to-purple-50

/* 主要按钮 */
bg-gradient-to-r from-indigo-500 to-purple-600
```

## 📱 交互流程

### 典型使用流程
1. **左栏**：选择渐变类型 → 调整色标和角度
2. **中栏**：实时预览 → 点击"生成渐变"
3. **右栏**：选择纹理效果 → 或选择预设快速开始

### API 调用时机
- **自动生成**：加载预设、随机生成
- **手动生成**：点击"生成渐变"按钮
- **应用效果**：点击纹理效果按钮

## 💡 设计优势

### ✅ 用户体验
- **逻辑清晰**：输入 → 预览 → 输出，从左到右的自然流程
- **视觉焦点**：中间预览区域最大，符合视觉重心
- **快捷访问**：常用效果和预设在右侧触手可及

### ✅ 空间利用
- **黄金比例**：3:6:3 接近视觉平衡
- **内容密度**：每个区域内容充实但不拥挤
- **滚动优化**：仅预设库可滚动，其他内容可见

### ✅ 技术优势
- **组件化**：每个区域独立，易于维护
- **响应式**：桌面三栏，移动单栏自适应
- **性能优化**：虚拟滚动（如需更多预设可扩展）
