## ✨ 特性

- **渐变设计**: 支持线性/径向渐变，多色标编辑，精确角度控制。
- **专业效果**: 支持噪点、晕影效果，实时预览。
- **智能功能**: 收藏夹、历史记录（撤销/重做）、随机生成。
- **双版本**: 提供现代化 Web 界面（推荐）和经典 Tkinter 桌面版。

## 🚀 快速开始

### 🌐 Web 版本（推荐）

基于 PyWebView + Vue 3，界面更现代。

```bash
# 克隆项目
git clone https://github.com/ViaVxxx/gradient_tool.git
cd gradient_tool

# 启动（自动安装依赖）
python start_web.py
```

### 🖥️ Tkinter 版本

经典桌面应用，无需 Node.js 环境。

```bash
pip install -r requirements.txt
python main.py
```

## 📖 使用指南

- **设计**: 选择渐变类型，拖动滑块调整角度，点击色条添加/修改颜色。
- **效果**: 调整噪点和晕影增强质感。
- **导出**: 设置分辨率，支持 PNG/JPG 导出。
- **快捷键**:
    - `Space` / `R`: 随机生成
    - `Ctrl+S`: 导出 PNG
    - `Ctrl+Z` / `Ctrl+Y`: 撤销 / 重做
