# Gradient Tool - Tkinter 桌面版

**经典桌面应用，稳定可靠的渐变色图像生成器**

## ✨ 特性

- 🎨 **多种渐变类型**: 线性渐变、径向渐变
- 🌈 **多色标编辑**: 支持最多 20 个色标点
- ✨ **专业效果**: 噪点、晕影、纹理效果
- ⭐ **收藏系统**: 保存和管理喜爱的渐变
- 🌙 **深色主题**: 现代化界面设计
- ⌨️ **快捷键支持**: 提升操作效率

## 🚀 快速开始

### 环境要求
```
Python 3.7+
tkinter (Python 内置)
Pillow >= 10.0.0
```

### 安装步骤

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **启动应用**
```bash
python main.py
```

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 导出 PNG 格式 |
| `Space` / `R` | 随机生成渐变 |
| `Ctrl+Z` | 撤销操作 |
| `Ctrl+Y` | 重做操作 |

## 📖 使用指南

### 基础操作
1. **选择渐变类型**: 线性或径向渐变
2. **调整角度**: 仅线性渐变可用，拖动滑块调节
3. **编辑色标**: 点击色标选择颜色，使用 +/- 按钮添加/删除
4. **应用效果**: 调节噪点和晕影强度
5. **设置分辨率**: 选择预设或自定义尺寸
6. **导出图像**: 支持 PNG/JPG 格式

### 高级功能
- **收藏管理**: 点击 ⭐ 收藏当前渐变，支持多选批量操作
- **预设使用**: 从分类预设中快速选择专业渐变
- **历史记录**: 使用撤销/重做功能回到之前的状态

## 🛠️ 技术栈

- **GUI 框架**: Tkinter (跨平台原生支持)
- **图像处理**: Pillow (PIL Fork)
- **渲染引擎**: 自研 Canvas 2D 渲染
- **架构模式**: MVC 分层架构
